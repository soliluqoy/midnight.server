# CPU measurements: Intel Core i7-8650U (2026-09-25)

**Scope:** single-machine measurements used to pick defaults. Not a release benchmark: small sample counts, one laptop, no thermal control, other processes running.

Machine: Windows 10 Pro 19045, Intel Core i7-8650U (4 cores / 8 threads), 15.9 GiB RAM, Intel UHD 620 (unused). Engine: llama.cpp `b11166` Windows CPU release. Model: `MiniCPM5-2B-Q8_0.gguf` (pinned, SHA-256 verified).

## Throughput by thread count

`llama-bench -p 512 -n 32 -t 4,6,8 -r 2`:

| Threads | Prompt processing (pp512), tokens/s | Generation (tg32), tokens/s |
| ---: | ---: | ---: |
| 4 | 20.17 ± 1.81 | 8.38 ± 0.55 |
| 6 | 24.94 ± 0.99 | 9.16 ± 0.03 |
| 8 | 28.77 ± 1.20 | 8.02 ± 0.00 |

Result: prompt processing scales to all logical cores, while generation peaks at 6. The engine now runs `--threads` = logical cores minus 2 (capped at 8) and `--threads-batch` = all logical cores.

## End-to-end timings

| Operation | Time | Notes |
| --- | ---: | --- |
| Engine start, model verification cached | 1.9 s | OS file cache warm |
| Engine start including first SHA-256 verification | 10.5 s | Verification is cached per file (path, size, mtime) afterwards |

## Memory

`llama-server` process after startup and after one short generation (Windows process counters):

| Context | Working set | Private bytes |
| ---: | ---: | ---: |
| 4,096 | 2,511 MiB | 341 MiB |
| 8,192 | 2,679 MiB | 513 MiB |

The weights are memory-mapped (shared, ~2.2 GiB). Private memory grows by ~170 MiB from 4K to 8K, which matches the plan's FP16 KV estimate (168 MiB per 4K tokens). The CLI process is not included.

## Implications

- On this class of CPU, prompt length dominates latency: about 25-30 tokens/s means ~70 s per 2,000 prompt tokens. Pi's agent system prompt plus tool definitions is paid once per session (llama-server reuses the cached prefix on later turns).
- Helper tasks default to thinking off for summarize/classify/inspect (about 4x faster in the one sample above) and on for plan/patch. This is a provisional default, not an evaluated one; the evaluation corpus in the plan (Phase 5) is still required.
- The default context is 8K rather than the plan's 4K: Pi's agent system prompt and tool definitions leave too little room in 4K, and the measured cost of 8K is ~170 MiB.
- GPU offload, CLI memory, and larger sample sizes were not measured.
