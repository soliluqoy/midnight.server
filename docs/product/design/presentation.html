Every surface.

05 / trust by design

Powerful enough to help.
Constrained enough to trust.

01

Observe before acting.
Read-only inspection is the default.

02

Ask before crossing boundaries.
Sending, deleting, purchasing and external communication require approval.

03

Leave an audit trail.
Every tool call, screenshot and decision can be reviewed or exported.

04

Stop means stop.
One global emergency action terminates active computer control.

08 / the path

Ship the feeling first.
Optimize with evidence.

PHASE 01

Visible missions

Desktop shell, floating chatbox, local RPC, live tool timeline and approvals.

PHASE 02

Real computer use

Screen observation, browser control, pause/stop, audit log and permissions.

PHASE 03

Native efficiency

Measure startup, idle RAM, active CPU and battery before moving hotspots native.

PHASE 04

Always useful

Autostart, recovery, offline queueing, handoffs, sharing and team policy.

✓

Decision gate: a full C/C++ rewrite happens only if measured runtime costs prevent the product from meeting its resource budget.
